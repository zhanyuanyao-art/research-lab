## 适用的问题

我们想知道 X 对 Y 的作用，但 X 不是随机分配的，它和误差项相关，这叫内生性。内生性有四个常见来源：

- **遗漏变量**：一个没观察到的因素同时影响 X 和 Y。比如两国关系的底色，既影响贸易，也影响冲突。
- **反向因果**：Y 也在影响 X。援助可能改善治理，治理好的国家也可能因此得到更多援助；维和行动可能缩短冲突，但维和部队往往被派到最难解决的冲突里。
- **测量误差**：X 测得不准，系数向 0 衰减。民主程度、国家能力这类概念指标，误差往往不小。
- **样本选择**：只观察到一部分单位，而进入样本的过程和 Y 有关。

这些情况下，最小二乘的系数里既有 X 的作用，也有上述种种污染。加控制变量只能处理观察得到的混杂；工具变量的思路是另找一个外生的推力，只用这股推力带来的 X 的变化。

## 核心思想

工具变量 Z 要做到三件事：它能推动 X；它和那些看不见的因素无关；它影响 Y 只通过 X 这一条路。三件事都成立，Z 和 Y 之间的关联就只能是经由 X 传过去的，于是：

```text
X 对 Y 的效果 = Z 对 Y 的效果 / Z 对 X 的效果
```

一个数字例子。设 Z 是一个二值的外部条件，比如某种规则使一部分国家更有可能获得某项国际支持：

| | Z = 1 的国家 | Z = 0 的国家 | 差 |
|---|---|---|---|
| X 的平均值，即获得支持的比例 | 0.6 | 0.2 | 0.4 |
| Y 的平均值 | 14 | 12 | 2 |

Z 把 X 推高了 0.4，这是第一阶段；把 Y 推高了 2，这是简约式。如果 Z 只能通过 X 影响 Y，那么 0.4 个单位的 X 带来了 2 个单位的 Y，每单位 X 的效果是 2 / 0.4 = 5。这叫 Wald 估计量，是工具变量最简单的形式。

这个比值也暴露了工具变量的软肋。假设 Z 除了通过 X，还直接让 Y 增加 0.2，真实效果应是 `(2 − 0.2) / 0.4 = 4.5`，工具变量却报告 5，偏了 0.5。如果第一阶段很弱，Z 只把 X 推高 0.1，同样 0.2 的直接作用造成的偏误就是 0.2 / 0.1 = 2。一般地：

```text
β̂_IV → β + Cov(Z, ε) / Cov(Z, X)
```

- `β` 是 X 的真实效果；
- `Cov(Z, ε)` 是工具和误差的相关，排他性或独立性被违反时不为 0；
- `Cov(Z, X)` 是第一阶段的强度。

分子哪怕很小，分母更小时偏误也会很大。**排他性的微小违反，会被弱的第一阶段放大**。所以弱工具和排他性要放在一起看，这是理解后面所有检验的钥匙。

## 模型设定

**结构方程**，我们关心的那一条：

```text
Y_i = β_0 + β_1·X_i + W_i′γ + ε_i
```

- `X_i` 是内生的解释变量；
- `W_i` 是外生的控制变量；
- `β_1` 是要估计的效果；
- `ε_i` 和 X_i 相关，所以直接回归有偏。

**第一阶段**：

```text
X_i = π_0 + π_1·Z_i + W_i′δ + v_i
```

- `Z_i` 是工具变量；
- `π_1` 是工具推动 X 的力度，必须不为 0；
- 外生控制变量 W 在两个阶段都要放。

**第二阶段**：

```text
Y_i = β_0 + β_1·X̂_i + W_i′γ + e_i
```

- `X̂_i` 是第一阶段的拟合值，只包含 Z 和 W 带来的那部分 X 的变化。

**简约式**：

```text
Y_i = ρ_0 + ρ_1·Z_i + W_i′κ + u_i
```

- `ρ_1` 是 Z 对 Y 的直接关联；
- 只有一个工具、一个内生变量时，`β̂_1 = ρ̂_1 / π̂_1`，正是上面的 Wald 比值。

几点技术细节：

- **不要手动做两步回归**。第二阶段直接用 X̂ 跑最小二乘，系数对，标准误错：残差应当用真实的 X 计算，而不是 X̂。要用专门的命令。
- **不要把非线性的第一阶段代进第二阶段**。比如 X 是二值，先跑 probit，再把预测概率当作 X 放进第二阶段，这叫被禁止的回归，估计不一致。正确的做法是把 probit 的预测概率当作工具，仍然用线性的两阶段最小二乘。
- **内生变量的交互项也是内生的**。模型里有 X × W，就要用 Z × W 作它的工具，不能只给 X 找工具。
- 工具多于内生变量时叫过度识别。除了两阶段最小二乘，还可以用有限信息最大似然 LIML，它在弱工具和工具很多时偏误更小；或者用 GMM，在异方差下更有效。

## 识别假设

1. **相关性**：Z 确实推动 X，`π_1 ≠ 0`，而且要足够强。这是唯一能直接检验的一条。不够强时，估计偏向最小二乘，标准误和置信区间失真。
2. **独立性**：控制 W 之后，Z 和那些同时影响 Y 的看不见的因素无关，Z 的取值近似随机。它保证第一阶段和简约式本身是因果效应。
3. **排他性**：Z 影响 Y 只通过 X，没有别的路径。这一条永远无法用数据直接检验，只能靠论证和间接证据。一项工具变量研究的说服力，大部分取决于这一条讲得好不好。
4. **单调性**：Z 对 X 的推动方向对所有单位相同，不存在 Z 让一部分单位的 X 上升、另一部分下降的情况。

**LATE：工具变量估计的是谁的效果**。X 的效果因单位而异时，以二值的 Z 和 X 为例，可以把单位分成四类：

- **遵从者**：Z = 1 时 X = 1，Z = 0 时 X = 0，X 随工具而变；
- **永远接受者**：无论 Z 是什么，X 都等于 1；
- **永远不接受者**：无论 Z 是什么，X 都等于 0；
- **违抗者**：Z = 1 时反而 X = 0，Z = 0 时反而 X = 1。

单调性就是假定没有违抗者。永远接受者和永远不接受者的 X 不随 Z 变化，对 Wald 比值没有贡献。所以在上述四条假设下，工具变量估计的是遵从者的平均处理效应，叫局部平均处理效应 LATE，而不是全体的平均效应。这有三个实际后果：

- 遵从者是谁，取决于工具。同一个 X，换一个工具，遵从者换了一批，估计值不同不一定说明哪个工具无效。
- 遵从者往往不是研究者最关心的群体。比如工具是某种影响援助的外部冲击，遵从者就是援助额会随这种冲击变化的那些受援国，它们未必代表所有受援国。
- 工具变量估计比最小二乘大很多时，至少有三种解释：遵从者的效应确实更大；最小二乘被测量误差压低了；排他性或独立性被违反，又被弱的第一阶段放大了。论文要说清楚是哪一种。

**弱工具与第一阶段 F**。第一阶段弱时，两阶段最小二乘有三个问题：估计向最小二乘偏；分布不再近似正态，常用的 t 检验拒绝原假设的频率远超名义水平；对排他性的微小违反极其敏感。判断强弱的标准经历了几次修正：

- 长期流行的经验法则是第一阶段 F 大于 10。它来自 Staiger 和 Stock 的研究，大意是 F 超过 10 时，两阶段最小二乘相对于最小二乘的偏误大致可以接受。
- Stock 和 Yogo 给出了更细的临界值：一个工具、一个内生变量时，要让名义 5% 的 t 检验实际拒绝率不超过 10%，F 要超过 16.38。
- Lee、McCrary、Moreira 和 Porter 在 2022 年指出：只有一个工具时，要让通常的 t 检验在 5% 水平上真正只有 5% 的拒绝率，F 要超过 104.7。F 不到这个数时，他们提出 tF 方法，按 F 的大小调高 t 的临界值；F 约为 10 时，临界值要从 1.96 提高到约 3.43。按这个标准，不少原本显著的结果会变得不显著。
- 还要看 F 是怎么算的。传统 F 和 Cragg–Donald 统计量假设误差同方差、无聚类；用了稳健或聚类标准误的研究，应当报告 Montiel Olea 和 Pflueger 的有效 F，只有一个工具时它就等于按同样方式算的稳健第一阶段 F。常见的 Kleibergen–Paap rk Wald F 也是稳健的，但拿它去比 Stock–Yogo 临界值只是一种近似。论文报了 F 却不说明是哪一种，是常见的漏洞。
- 不依赖工具强弱的推断：Anderson–Rubin 检验和置信集。它在工具弱时检验水平依然正确；工具很弱时，它给出的置信集会很宽，甚至无界，这正是诚实的回答。只有一个工具时，检验 β_1 = 0 的 AR 检验就是简约式里 Z 的系数检验。

Lal、Lockhart、Xu 和 Zu 复现了几十篇发表在政治学顶级期刊上的工具变量研究，发现研究者常因忽略聚类而高估工具强度，常规 t 检验低估了不确定性；多数研究的两阶段最小二乘估计远大于最小二乘，而在非实验产生的工具里，这个倍数和工具强度负相关，提示排他性或独立性可能出了问题。

**过度识别检验**。工具多于内生变量时，可以做 Sargan 或 Hansen J 检验，看各个工具给出的估计是否互相一致。它的局限很大：

- 原假设是所有工具都有效，实际检验的是工具之间是否一致。如果所有工具都以同样的方式违反排他性，它们彼此一致，检验照样通过。
- 它需要至少一个有效的工具作基准，而哪一个有效，检验本身说不出来。
- 效应异质时，不同工具估计的是不同遵从者的 LATE，本来就可以不同，拒绝原假设不一定意味着工具无效。
- 工具很多时，检验的功效急剧下降，p 值会接近 1，看起来很好，其实说明不了问题。
- 恰好识别时无法进行。

所以过度识别检验没通过是个警讯，通过了却不能当作排他性成立的证据。

**简约式**。Y 直接对 Z 回归。它只需要独立性，不需要排他性和相关性，估计的就是 Z 对 Y 的因果效应，也不受弱工具的影响。工具变量估计只是简约式除以第一阶段：简约式看不出关系，工具变量的显著结果就值得怀疑；简约式的符号乘以第一阶段的符号，必须和工具变量估计的符号对得上。读工具变量论文，可以先找简约式。

**国际关系里常见的几类工具**，以及各自在排他性上的难点：

- **地理和距离**：用离某地的远近、是否沿海、地形等，作为贸易、援助、媒体覆盖的工具。难点是地理几乎影响一切，很难说它只通过某一个 X 影响结果。
- **历史条件**：用殖民时期或更早的条件作为今天制度的工具。难点是历史条件会通过人口、文化、人力资本等多条路径延续到今天。
- **天气和自然冲击**：用降雨、气温、自然灾害作为经济增长或农业收入的工具，研究冲突或政治动荡。难点是同一种冲击被不同论文用作许多不同 X 的工具；每多一篇论文发现降雨影响某个变量，就多一条可能绕开 X 的路径。
- **外部总量乘以历史份额**：比如用捐助国自身的预算或产量波动，乘以各受援国过去接受援助的频率，构造每个受援国每年的工具。难点是历史份额本身可能和结果的走势相关，这时工具并不外生。
- **地区扩散**：用邻国或同地区其他国家的平均水平作为本国 X 的工具，比如地区性的民主化浪潮。难点是地区性冲击可能直接影响本国结果，比如一场地区经济危机同时传导到所有国家。
- **制度规则和轮换**：任期限制、按规则轮换的席位、抽签。这类工具的独立性最好，但遵从者往往很窄，结论能推多远要谨慎。
- **X 的滞后值**：用去年的 X 作为今年 X 的工具。只要误差有序列相关，或者过去的 X 本身直接影响今天的 Y，它就无效。审稿人对这种做法普遍不信任。

**为什么审稿人不信任很多工具**：

- 工具越多，第一阶段越容易过度拟合，X̂ 越接近 X 本身，两阶段最小二乘就越接近有偏的最小二乘。极端情况下工具和观测一样多，第一阶段完美拟合，X̂ 就是 X。
- 每个工具都需要自己的排他性论证。工具越多，至少有一个无效的可能越大。
- 工具多时过度识别检验的功效很低，通过检验说明不了什么。
- 工具很多常常意味着作者在多种组合里挑选过，挑选本身就会让结果看起来比实际更可信。

一个强、有清楚故事的工具，胜过十个弱而含糊的工具。

## 稳健性检验：做什么，为什么

每一项检验都对应上面的某条假设。读论文时，可以对照着看作者做了哪些、漏了哪些。

| 检验 | 检查哪条假设 | 怎么做，怎么看 |
|---|---|---|
| 报告第一阶段 | 相关性 | 列出 Z 对 X 的系数、符号和稳健的 F。符号要和作者讲的机制一致；F 只和 10 比已经不够，还要对照 Stock–Yogo 临界值或 104.7 这条线 |
| Anderson–Rubin 置信集或 tF 修正 | 相关性不够强时推断是否可靠 | 两阶段最小二乘显著而 AR 置信集包含 0，或者按 F 调高临界值后不再显著，说明显著性来自弱工具造成的失真 |
| 简约式 | 结论能否从工具直接看到 | Y 对 Z 回归，系数应当显著，符号与第一阶段、工具变量估计对得上。简约式都看不出关系，工具变量结果多半是弱第一阶段放大的噪声 |
| 工具与事前特征的平衡 | 独立性 | 用 Z 去解释在它之前就确定的变量，或者 X 发生之前的 Y。Z 能解释它们，说明 Z 和看不见的因素相关，并非近似随机 |
| 零第一阶段的安慰剂样本 | 排他性 | 找一个 Z 不可能影响 X 的子样本，比如没有资格获得这项支持的国家，在那里做简约式。Z 依然影响 Y，说明 Z 有绕开 X 的路径 |
| 控制替代渠道 | 排他性 | 把 Z 可能绕开 X 影响 Y 的渠道作为控制变量加入，前提是这些渠道不受 X 影响。估计稳定，说明这些渠道不是主要问题 |
| 部分违反排他性的敏感性分析 | 排他性 | 用 Conley、Hansen 和 Rossi 的方法，允许 Z 对 Y 有一个大小为 γ 的直接作用，看 γ 要多大结论才会翻转。所需的 γ 越大，结论越稳；拿 γ 和简约式的大小比一比，就知道多大的违反算合理 |
| 过度识别检验，逐个工具单独估计 | 多个工具之间是否一致 | 做 Hansen J 检验，并分别用每个工具单独估计。各工具的估计接近，说明它们至少讲的是同一个故事；差别大，可能有无效工具，也可能是不同的 LATE |
| 比较最小二乘与工具变量 | 内生性的方向，以及 LATE 的解释 | 差距的方向要和作者讲的内生性来源对得上。比如作者说援助流向治理差的国家，最小二乘应当低估援助的正面作用，工具变量估计应当更大；方向反了，或者大出好几倍，就要追问原因 |
| LIML 与两阶段最小二乘对比 | 多工具或弱工具造成的偏误 | LIML 在这两种情况下偏误更小。两者接近，说明偏误不严重；差别大，要警惕弱工具 |
| 逐个剔除单位或聚类 | 第一阶段是否由少数观测撑起 | 每次去掉一个国家，重估第一阶段和工具变量估计。第一阶段只靠一两个国家时，F 可能很高，结论却很脆弱 |

## 怎么读结果

- **系数的含义**：单位和最小二乘相同，读作 X 每增加一个单位 Y 的变化，但它是遵从者的平均效应。
- **表格的排法**：常见的是并排几列：最小二乘、第一阶段、简约式、两阶段最小二乘。依次看：第一阶段的系数和 F，简约式的符号和显著性，两阶段估计和最小二乘差多少。
- **F 的名称**：First-stage F、Cragg–Donald Wald F、Kleibergen–Paap rk Wald F、Effective F。前两个在聚类误差下不可靠，后两个是稳健的。
- **识别不足检验**：ivreg2 输出里的 Underidentification test，检验的是方程是否根本无法识别。通过它只说明工具不是完全无关，不说明工具够强。
- **内生性检验**：Durbin–Wu–Hausman 检验比较最小二乘和工具变量估计。没有拒绝不等于 X 是外生的；工具变量标准误大，这个检验的功效常常很低。
- **Hansen J**：给出过度识别检验的 p 值，局限见上。
- **标准误**：工具变量的标准误一般比最小二乘大好几倍，这是用一部分变化换取一致性的正常代价。工具变量估计比最小二乘更显著，反而要多看一眼。

读的时候可以这样说：以 Z 为工具，第一阶段的有效 F 为某值；X 每增加一个单位，使受工具影响的那部分单位的 Y 平均变化 β_1；简约式显示 Z 本身使 Y 变化 ρ_1，方向一致；在 Anderson–Rubin 置信集下结论依然成立。

## 常见陷阱

- **手动做两步最小二乘**：系数对，标准误错。
- **被禁止的回归**：把 probit 或 logit 的第一阶段预测值当作 X 代进第二阶段。
- **控制变量只放在一个阶段**：所有外生控制变量都要同时出现在两个阶段。
- **内生交互项没有相应的工具**。
- **聚类误差下报告不稳健的 F**：工具强度被高估。
- **用 F > 10 预先筛选设定**：只报告 F 过关的设定，本身也会扭曲推断。
- **把过度识别检验通过当成排他性成立的证明**。
- **把 LATE 当成总体的平均效应外推**。
- **用滞后的 X 作工具**，而不讨论误差的序列相关和滞后 X 的直接作用。
- **工具变量估计远大于最小二乘却不解释**：测量误差可以解释一部分，倍数大到离谱时，更可能是排他性违反被弱第一阶段放大。

## 代码写法

R，常用 fixest，也可以用 ivreg 包：

```r
library(fixest)
# 三段式公式：结果 ~ 外生控制 | 固定效应 | 内生变量 ~ 工具
iv1 <- feols(y ~ w1 + w2 | country + year | x ~ z, data = df, cluster = ~country)
summary(iv1, stage = 1)          # 第一阶段
etable(iv1, stage = 1:2)         # 第一阶段与第二阶段并列
fitstat(iv1, ~ ivf + ivwald + wh)
# ivf 是传统的第一阶段 F；ivwald 按模型的聚类方式计算，只有一个工具时即为有效 F
# wh 是 Wu–Hausman 内生性检验

# 没有固定效应时省掉中间一段；两个工具，过度识别时才能做 Sargan 检验
iv2 <- feols(y ~ w1 | x ~ z1 + z2, data = df, cluster = ~country)
fitstat(iv2, ~ ivwald + sargan)

# 简约式：结果直接对工具回归
rf <- feols(y ~ z + w1 + w2 | country + year, data = df, cluster = ~country)

# Anderson–Rubin：检验 β = b0，等于在 y − b0·x 对 z 的回归里检验 z 的系数
# 在网格上逐一检验，不被拒绝的 b0 组成 AR 置信集；它不一定连续，网格两端都不被拒绝时可能无界
grid <- seq(-2, 10, by = 0.05)
ar_p <- sapply(grid, function(b0) {
  df$y_b0 <- df$y - b0 * df$x
  m <- feols(y_b0 ~ z + w1 + w2 | country + year, data = df, cluster = ~country)
  pvalue(m)["z"]
})
range(grid[ar_p > 0.05])

# ivreg 包：竖线前是结构方程，竖线后是全部外生变量，即工具加外生控制
library(ivreg)
iv3 <- ivreg(y ~ x + w1 + w2 | z + w1 + w2, data = df)
summary(iv3, diagnostics = TRUE)  # 弱工具检验、Wu–Hausman、Sargan
```

```python
from linearmodels.iv import IV2SLS, IVLIML
# 方括号里是 内生变量 ~ 工具
res = IV2SLS.from_formula("y ~ 1 + w1 + w2 + [x ~ z1 + z2]", data=df).fit(
    cov_type="clustered", clusters=df["country"])
print(res.first_stage)   # 第一阶段诊断，含偏 R² 和 F
print(res.sargan)        # sargan 假定同方差无聚类；聚类误差下改看 res.wooldridge_overid
liml = IVLIML.from_formula("y ~ 1 + w1 + w2 + [x ~ z1 + z2]", data=df).fit(
    cov_type="clustered", clusters=df["country"])

import pyfixest as pf
# 与 fixest 相同的三段式公式
iv = pf.feols("y ~ w1 + w2 | country + year | x ~ z", data=df, vcov={"CRV1": "country"})
```

在作者代码里认工具变量，看这几处：fixest 和 pyfixest 公式的最后一段 `x ~ z`；`ivreg` 或 `AER::ivreg` 公式里竖线后面那组变量；`felm` 公式第三段的 `(x ~ z)`，`estimatr::iv_robust`；Stata 括号里的等号 `(x = z)`，以及 `ivregress`、`ivreg2`、`xtivreg`、`ivreghdfe`、`ivprobit`；Python 的 `IV2SLS`、`IVLIML` 和方括号 `[x ~ z]`。还有几处旁证：单独跑的第一阶段和简约式回归，`estat firststage`、`weakivtest`、`first` 选项，`liml`、`gmm` 估计量。

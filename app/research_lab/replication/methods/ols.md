summary: 找一组系数，让预测值和实际值之差的平方和最小；每个系数读作其他变量不变时，这个变量多一单位，结果平均变化多少。

## 适用的问题

因变量是一个连续的数，我们想知道它怎样随几个解释变量变化。比如：

- 一国军费占 GDP 的比重，和它面临的外部威胁、邻国军费有什么关系；
- 两国之间的贸易额，和是否结盟、是否同为民主国家有什么关系；
- 一位议员的投票立场得分，和选区特征、所属政党有什么关系。

最小二乘是所有回归的起点，后面几章的 Logit、泊松、负二项，都可以看作它在因变量不连续时的改写。也正因为用得最多，它最容易被误读：最小二乘本身只是一种拟合方法，算出来的是条件平均值怎样随解释变量变化；这个系数能不能读成因果效应，取决于下面的假设，而不取决于回归本身。

## 核心思想

画一张散点图，想找一条直线代表这些点。每个点到直线都有一段竖直距离，叫残差。最小二乘选的那条线，让所有残差的平方加起来最小。

为什么用平方：正负残差不会互相抵消；大的偏离受到更重的惩罚；而且有闭合解，直接用公式算出，不需要迭代。代价是平方会放大离群点的影响，一两个极端观测就可能把直线拉偏。

一个数字例子，五个国家：

| 国家 | X | Y | 拟合值 | 残差 |
|---|---|---|---|---|
| A | 0 | 2 | 2.2 | −0.2 |
| B | 1 | 3 | 3.1 | −0.1 |
| C | 2 | 5 | 4.0 | +1.0 |
| D | 3 | 4 | 4.9 | −0.9 |
| E | 4 | 6 | 5.8 | +0.2 |

X 的均值是 2，Y 的均值是 4。斜率等于 X 与 Y 的离差乘积之和除以 X 的离差平方和，即 9 ÷ 10 = 0.9；截距是 4 − 0.9 × 2 = 2.2。残差加起来正好是 0，平方和是 1.9；换任何一条别的直线，平方和都会更大。

有多个解释变量时，系数的含义变成**其他变量不变**。X₁ 的系数等于两步的结果：先用其他解释变量去解释 X₁，取出解释不了的那部分；再看 Y 怎样随这部分变化。这叫 Frisch–Waugh–Lovell 定理。它说明了“控制”一个变量的真实含义：只用 X₁ 中和控制变量无关的那部分变异来估计效果。如果 X₁ 几乎完全被控制变量解释，剩下的变异很少，系数就会很不精确。

## 模型设定

```text
Y_i = β_0 + β_1·X_1i + β_2·X_2i + … + β_k·X_ki + ε_i
```

- `Y_i`：第 i 个观测的因变量；
- `X_1i … X_ki`：k 个解释变量；
- `β_0`：截距，所有 X 都取 0 时 Y 的平均值；
- `β_j`：其他解释变量不变时，X_j 增加一单位，Y 平均变化多少；
- `ε_i`：误差项，Y 中所有没被这些 X 解释的因素。

最小二乘的目标和解：

```text
β̂ = argmin_b Σ_i (Y_i − b_0 − b_1·X_1i − … − b_k·X_ki)²
β̂ = (X′X)⁻¹ X′Y
```

- `β̂`：系数的估计值，加帽子表示从样本算出；
- `argmin_b`：让后面的式子取最小值的那组 b；
- `X`：n 行、k + 1 列的矩阵，每行一个观测，第一列全是 1，对应截距；
- `X′`：X 的转置；`(X′X)⁻¹` 是 X′X 的逆矩阵，它存在要求解释变量之间没有完全共线；
- 残差 `e_i = Y_i − Ŷ_i` 是误差项 ε_i 在样本里的对应物，`Ŷ_i` 是拟合值。

**交互项**：一个变量的效果随另一个变量变化。

```text
Y_i = β_0 + β_1·X_i + β_2·Z_i + β_3·(X_i × Z_i) + ε_i
∂Y/∂X = β_1 + β_3·Z
Var(β̂_1 + β̂_3·Z) = Var(β̂_1) + Z²·Var(β̂_3) + 2Z·Cov(β̂_1, β̂_3)
```

- `X_i × Z_i`：两个变量的乘积；
- `∂Y/∂X`：Z 固定在某个值时，X 增加一单位 Y 的变化，即 X 的边际效应，它随 Z 而变；
- `β_1`：Z = 0 时 X 的效果，不是 X 的平均效果，也不是所谓主效应；Z 取不到 0 时，β_1 本身没有实际意义；
- `β_3`：Z 每增加一单位，X 的效果增加多少；
- `Var`、`Cov`：方差和协方差；第三行是边际效应的方差，开方即标准误，它要用到两个系数的协方差，所以只看表格里两个系数各自的标准误判断不了。

为什么低阶项 X 和 Z 必须留在模型里：去掉 β_2·Z，等于强行假定 X = 0 时 Z 对 Y 毫无作用。这个假定通常没有理由，一旦不成立，Z 本身的作用就会挤进乘积项，β_3 随之有偏。另一个现象也说明低阶项不能单独读：把 Z 减去均值后重新估计，β_1 变成 Z 取均值时 X 的效果，数值会变，但 β_3 和每个 Z 值上的边际效应完全不变。

**对数变量**：

| 设定 | 系数 β 的读法 |
|---|---|
| log Y 对 X | X 增加一单位，Y 约变化 100·β%；精确值是 `100·(exp(β) − 1)%` |
| Y 对 log X | X 增加 1%，Y 约变化 β/100 个单位 |
| log Y 对 log X | X 增加 1%，Y 约变化 β%，即弹性 |

近似只在 β 小的时候好用：β = 0.05 时精确值是 5.1%，和 5% 差不多；β = 0.3 时，`exp(0.3) − 1 = 0.35`，是 35% 而不是 30%。Y 有 0 时取不了对数，常见的 `log(Y + 1)` 会让结果依赖 Y 的计量单位；次数型的因变量更适合用泊松回归。

**线性概率模型**：Y 只取 0 和 1 时直接用最小二乘，β 读作 X 增加一单位，Y = 1 的概率变化多少。它的误差方差是 `p(1 − p)`，随 X 变化，天生异方差，所以一定要用稳健标准误；预测值可能跑出 0 到 1 之间。它估计的平均效应往往和 Logit 的平均边际效应很接近，加大量固定效应时也没有 Logit 的麻烦，细节见 Logit 与 Probit 一章。

## 识别假设

最小二乘本身不是因果识别设计。下面是教科书上的高斯–马尔可夫条件，加上推断需要的条件。每一条失败的后果不同：有的让系数本身错，有的只让标准误错。

1. **对参数是线性的**：Y 是各个 β 的线性组合。X 本身可以取对数、平方、交互，只要 β 是线性进入的。真实关系是弯的而模型写成直线，系数就成了某种加权平均斜率，在样本的某些区段会误导。
2. **随机抽样，观测相互独立**：国家–年份面板、同一国家的多个受访者，都违反这一条。系数不偏，但普通标准误通常太小。
3. **没有完全共线**：没有哪个解释变量是其他解释变量的线性组合。完全共线时无法估计，软件会自动丢掉一个变量。高度但不完全的共线不造成偏误，只让标准误变大。
4. **零条件均值**：`E(ε_i | X_i) = 0`，误差项与解释变量无关。这是最关键的一条，也是决定系数能否读成因果的那一条。遗漏变量、反向因果、解释变量的测量误差、样本选择，都违反它。违反后系数有偏而且不一致，样本再大也不会变对，换什么标准误都救不了。
5. **同方差**：误差方差不随 X 变化。违反后系数仍然无偏，但普通标准误公式错了，最小二乘也不再是线性无偏估计量里方差最小的。修正办法是稳健标准误。
6. **误差服从正态分布**：只在小样本里为 t 检验和 F 检验提供精确分布，对系数是否无偏不起作用。样本较大时，中心极限定理让检验近似成立。

前五条成立时，最小二乘是所有线性无偏估计量里方差最小的，这就是高斯–马尔可夫定理。概括地说：第 4 条管系数对不对，第 2、5 条管标准误对不对。

**遗漏变量偏误**。真实模型是 `Y = β_0 + β_1·X + β_2·Z + ε`，回归时却漏掉了 Z：

```text
plim β̃_1 = β_1 + β_2·δ
δ = Cov(X, Z) / Var(X)
```

- `β̃_1`：漏掉 Z 后 Y 对 X 回归得到的系数；
- `plim`：样本无限增大时估计值收敛到的值；
- `β_2`：Z 对 Y 的作用；
- `δ`：用 X 去解释 Z 得到的斜率，代表 X 和 Z 相关的方向和强度；
- `β_2·δ`：偏误。两个条件同时满足才有偏误：Z 影响 Y，并且 Z 和 X 相关。

偏误的方向由两个符号决定：

| | Z 与 X 正相关，δ > 0 | Z 与 X 负相关，δ < 0 |
|---|---|---|
| Z 使 Y 增加，β_2 > 0 | 向上偏，高估 | 向下偏，低估 |
| Z 使 Y 减少，β_2 < 0 | 向下偏，低估 | 向上偏，高估 |

一个数字例子：研究民主对贸易额的作用，漏掉了经济规模。设民主的真实作用 β_1 = 0.5，经济规模对贸易的作用 β_2 = 2，民主国家平均更富，δ = 0.4。漏掉经济规模的回归会得到 0.5 + 2 × 0.4 = 1.3，把效果夸大了一倍多。读论文时可以用这个逻辑推理：作者没控制的那个变量，按常识它和 X、Y 分别是什么方向的关系，偏误就往哪边走。如果偏误的方向是把效果往 0 拉，而结果仍然显著，结论反而更可信。

解释变量的测量误差是另一种违反：X 被随机误差污染时，系数会向 0 衰减。用粗略的指数衡量民主程度时，要想到估计值可能偏小。

**两种稳健标准误**：

- **异方差稳健标准误**，也叫 White 或 Huber–White 标准误，有 HC0 到 HC3 几种小样本修正。Stata 的 `robust` 是 HC1；R 的 sandwich 包 `vcovHC` 默认 HC3；estimatr 的 `lm_robust` 默认 HC2。截面数据、线性概率模型，以及没有理由相信误差方差恒定的场合都应使用。它只修正标准误，不碰系数。
- **聚类稳健标准误**，允许同一组内的误差任意相关，只假定组与组之间独立。需要它的情形：同一国家不同年份的观测，同一国家的多个受访者，同一对国家的多年观测。聚类层级一般选处理分配的层级，或误差可能相关的最高层级。聚类只有几十个甚至更少时，聚类标准误本身偏小，改用野聚类自助法。两个维度都有相关时，比如国家和年份，用双向聚类；双边数据里一个国家出现在很多国家对中，需要专门的二元组聚类，Aronow、Samii 和 Assenova 讨论过这种做法。

稳健标准误和普通标准误差得很大，本身就是一个信号。King 和 Roberts 指出，这往往意味着模型设定有问题，比如函数形式错了，而稳健标准误只是把问题盖住了。

**控制变量的选择**。好的控制变量是混杂因素：它同时影响 X 和 Y，而且在 X 之前就已经确定。坏控制有三类：

- **中介变量**：X 通过它影响 Y。研究民主对冲突的作用时控制贸易依存度，而民主本身会促进贸易，那么民主通过贸易减少冲突的那部分就被控制掉了，剩下的只是直接效应。
- **对撞变量**：同时被 X 和 Y 影响的变量。控制它会在 X 和 Y 之间凭空制造相关。如果样本只包括进入了危机的国家对，而 X 和 Y 都会影响一对国家是否进入危机，那么在这个样本内比较，就等于控制了对撞变量。
- **X 的后果**：处理发生之后才测量、受处理影响的变量，道理同中介变量。

控制变量不是越多越好，每加一个都要能说清它属于哪一类。

## 稳健性检验：做什么，为什么

政治学论文里最小二乘结果的稳健性检验，大多在回答两个问题：系数会不会是遗漏变量或设定方式造成的；标准误是不是太乐观。

| 检验 | 检查哪条假设 | 怎么做，怎么看 |
|---|---|---|
| 逐步加入控制变量 | 零条件均值：遗漏变量 | 从只放核心变量到加入全部控制变量，看系数怎么变。加入可观测的混杂因素后系数大幅缩小，说明选择问题严重，没观测到的变量也可能起作用；系数基本不动，才让人放心一些。Oster 的方法把系数的变化和 R² 的变化结合起来，估算不可观测因素要多强才能把效果推到 0 |
| 遗漏变量敏感性分析 | 零条件均值：遗漏变量 | Cinelli 和 Hazlett 的稳健值：一个没观测到的混杂因素要解释 X 和 Y 各多大比例的剩余变异，结论才会翻转。再拿已知最强的控制变量做基准，判断这样强的混杂因素是否现实 |
| 加入国家和年份固定效应 | 零条件均值：不随时间变化的遗漏变量、共同冲击 | 国家固定效应把比较限制在同一国家内部的变化，年份固定效应扣掉同一年所有国家共同的冲击。加入后系数消失，说明原来的关联主要来自国家之间的稳定差别。估计对象也随之改变：只剩国家内部随时间的变异，X 变化很少时估计会很不精确 |
| 换标准误：稳健、聚类、双向聚类、野自助法 | 同方差、观测独立 | 依次报告，系数不变，看显著性是否依赖某一种标准误。聚类少时以野自助法的 p 值为准；稳健标准误和普通标准误差得多时，回头检查函数形式 |
| 剔除有影响的观测 | 结论不靠少数观测，也检查离群点 | 看 Cook 距离、DFBETA，或者每次去掉一个国家、一个地区、一个年代重新估计。去掉某一个大国后结论消失，说明结果是少数案例撑起来的 |
| 改变函数形式 | 对参数线性、设定正确 | 加平方项，把 X 切成几个区间各放一个哑变量，或者换成对数。不同区段的效果方向不一，说明直线掩盖了重要的非线性 |
| 换测量和数据来源 | 测量误差 | 民主换用另一套指数或二分法，冲突换用不同门槛的数据集。不同测量给出一致结论，说明结论不是某种编码规则的产物 |
| 解释变量滞后一期 | 反向因果 | 用 t − 1 期的 X 解释 t 期的 Y 是常见做法。但 X 持续性很强、或者 Y 能被预期时，滞后排除不了反向因果；Bellemare、Masaki 和 Pepinsky 讨论了它反而引入偏误的情形。只能当作很弱的证据 |
| 分样本估计 | 效应同质 | 冷战前后、不同地区、不同政体分开估计。系数差别很大时，全样本的平均系数可能掩盖了方向相反的子群体 |
| 交互项的分箱估计 | 交互效应是线性的、调节变量有共同支撑 | Hainmueller、Mummolo 和 Xu 建议把 Z 分成低、中、高三段，各估计一个 X 的效果，看三点是否大致落在一条直线上；同时检查 Z 的每一段里 X 都有足够的变化 |

还要强调一点：这些检验都只在已经观测到的变量上做文章。它们能说明结果对哪些选择敏感，但证明不了没有遗漏变量；因果解读最终要靠研究设计，比如双重差分、工具变量、断点回归。

## 怎么读结果

- **系数的大小**：单位是 Y 的单位除以 X 的单位。判断是否重要，要和 Y 的标准差或均值比较，比如 X 增加一个标准差，Y 变化多少个标准差。
- **显著性**：t 值等于系数除以标准误，绝对值大约超过 2 时在 5% 水平显著。显著只说明不太可能是 0，不说明效果大；样本大时，微不足道的效果也能显著。置信区间比星号信息多。
- **截距**：所有 X 都取 0 时的预测值。X 取 0 不现实时，比如人口为 0，截距没有意义。
- **R²**：Y 的变异有多大比例被模型解释。跨国数据里 R² 低很常见，不说明模型错；R² 高也不说明系数可以读成因果。加入固定效应后 R² 会大涨，这时通常看组内 R²。
- **交互项**：不要只看 β_3 的星号，要画边际效应图：横轴是 Z，纵轴是 X 的边际效应 β_1 + β_3·Z 及其置信区间，图下方标出 Z 的分布。β_3 显著，不等于 Z 的每个取值上 X 的效果都显著；β_3 不显著，也不等于 X 的效果在任何 Z 上都不显著。
- **表格里要找的信息**：观测数、聚类数、标准误类型和聚类层级、固定效应、控制变量清单。

读的时候可以这样说：控制经济规模、距离和年份固定效应后，同为民主国家的国家对，贸易额平均高出 β 个单位；标准误按国家对聚类，在 5% 水平显著；换一种民主测量，系数大小基本不变。

## 常见陷阱

- **把条件相关读成因果**：系数只描述条件平均值的差别，因果读法需要零条件均值这条假设有说服力。
- **以为稳健标准误能修正偏误**：它只修正标准误，遗漏变量造成的偏误换什么标准误都一样。
- **把交互模型里的 β_1 读成主效应**：它只是 Z = 0 时 X 的效果。
- **去掉交互项的低阶项**：β_3 会吸收被去掉的那项作用，结果有偏。
- **控制了中介变量或对撞变量**：控制变量越多，并不越安全。
- **因为共线性删掉混杂因素**：方差膨胀因子高只说明不精确；删掉一个真正的混杂因素，换来的是偏误。
- **大系数的对数近似**：β = 0.3 读成 30% 是错的，应是 35%。
- **线性概率模型不用稳健标准误**：它的误差必然异方差。
- **一个显著、一个不显著，就说两个系数不同**：两者之差是否显著要单独检验，显著与不显著之间的差别本身未必显著。
- **在很多设定里挑显著的那个报告**：每多试一个设定，偶然显著的机会就多一分。

## 代码写法

R，基本回归用 lm，固定效应用 fixest，标准误用 sandwich：

```r
# 基本回归
m1 <- lm(y ~ x + z1 + z2, data = df)
summary(m1)

# 异方差稳健标准误与聚类标准误
library(sandwich)
library(lmtest)
```

Python：

```python
import statsmodels.formula.api as smf
import pyfixest as pf

# 异方差稳健标准误 HC1
m1 = smf.ols("y ~ x + z1 + z2", data=df).fit(cov_type="HC1")
# 按国家聚类；df 需先去掉相关变量的缺失值，groups 才能和样本对齐
m2 = smf.ols("y ~ x + z1 + z2", data=df).fit(cov_type="cluster", cov_kwds={"groups": df["country"]})
# 交互项
m3 = smf.ols("y ~ x * z + w", data=df).fit(cov_type="HC1")
# 固定效应加聚类
m4 = pf.feols("y ~ x + z1 + z2 | country + year", data=df, vcov={"CRV1": "country"})
```

在作者代码里认最小二乘，看这几处：R 的 `lm(`、`feols(`、`felm(`、`lm_robust(`、`plm(`，以及没写 `family` 或写着 `gaussian` 的 `glm(`；Stata 的 `reg`、`regress`、`areg`、`reghdfe`、`xtreg`；Python 的 `smf.ols`、`sm.OLS`、`pf.feols`。标准误的写法说明作者怎样处理异方差和相关：`vce(robust)`、`vce(cluster ...)`、`vcovHC`、`vcovCL`、`cluster = ~`、`se_type`。交互项看公式里的 `*`、`:` 和 Stata 的 `#`、`##`。因变量是 0/1 而命令仍是这些回归命令，就是线性概率模型。

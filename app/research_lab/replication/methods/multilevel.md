## 适用的问题

数据有嵌套结构：低一层的观测属于高一层的组，同组的观测彼此相像。比如：

- 跨国民意调查：受访者嵌套在国家里，既想知道个人的教育程度如何影响对自由贸易的态度，也想知道国家的经济开放程度起什么作用；
- 各届政府的历次会议：会议嵌套在届别里，同一届的会议共享领导人和议程；
- 国家—年份面板：各年份嵌套在国家里，可以看作对同一国家的重复测量；
- 更复杂的结构：选民嵌套在选区、选区嵌套在国家，形成三层；二元组同时属于两个国家，形成交叉分类。

多层模型适合回答这几类问题：

- 结果的差异有多少在组内、多少在组间；
- 组层面的变量有什么作用，比如政体、经济规模、制度安排，这些变量在组内不变，固定效应估不出来；
- 一个个人层面的效应是否因组而异，组层面的变量能否解释这种差异，即跨层交互；
- 有些组观测很少，希望得到比单独估计更稳的组别估计。

## 核心思想

处理分组数据有三种办法：

- **完全汇总**：不理会分组，所有观测共用一个截距。组与组之间确有差别时，同组观测的误差彼此相关，标准误被低估；组层变量的效应还会和遗漏的组间差异混在一起。
- **完全不汇总**：每组单独一个截距，也就是固定效应。观测少的组，截距全凭几个点估出来，噪声很大。
- **部分汇总**：每组的截距是本组均值和全体均值的加权平均。本组观测多、组间差异大时，更相信本组；本组观测少、组间差异小时，更向全体均值靠拢。这种向中间靠拢叫作收缩。

在只有随机截距、没有解释变量的模型里，组 j 截距的估计近似为：

```text
α̂_j = w_j · ȳ_j + (1 − w_j) · μ̂
w_j = τ² / (τ² + σ² / n_j)
```

- `ȳ_j` 是组 j 的样本均值，`μ̂` 是全体均值；
- `τ²` 是组间方差：各组真实均值彼此差多少；
- `σ²` 是组内方差：同组观测彼此差多少；
- `n_j` 是组 j 的观测数，`σ² / n_j` 就是组均值本身的抽样方差；
- `w_j` 是对本组数据的信任程度，介于 0 和 1 之间。

一个数字例子。一项跨国调查里，某个态度指标的全体均值是 50；组间方差 τ² = 25，即各国真实均值的标准差约为 5；组内方差 σ² = 400，即同一国家受访者之间的标准差约为 20。两个国家的样本均值都是 60：

| | 样本量 | 样本均值 | 组均值的抽样方差 | 权重 w_j | 收缩后的估计 |
|---|---|---|---|---|---|
| 甲国 | 100 | 60 | 400 / 100 = 4 | 25 / 29 ≈ 0.86 | 50 + 0.86 × 10 ≈ 58.6 |
| 乙国 | 4 | 60 | 400 / 4 = 100 | 25 / 125 = 0.20 | 50 + 0.20 × 10 = 52.0 |

甲国有 100 个受访者，60 这个均值相当可靠，只被轻轻拉回一点；乙国只有 4 个受访者，在组内标准差为 20 的情况下，4 个人平均出 60 完全可能是运气，模型把它大幅拉回到 52。这就是多层模型借力于全体的方式：它不是武断地把各组看成一样，而是让数据决定每一组该相信自己多少。

**组内相关系数**，记作 ICC，衡量结果的总方差里有多大比例来自组间：

```text
ICC = τ² / (τ² + σ²)
```

- `τ²` 是组间方差，`σ²` 是组内方差，两者之和是结果的总方差。

上例中 ICC = 25 / 425 ≈ 0.06，约 6% 的差异来自国家之间。它也等于随机挑同一国家两名受访者，二人结果之间的相关系数。

6% 看起来很小，对标准误的影响却很大。每组 m 个观测时，忽略分组造成的方差膨胀约为：

```text
设计效应 = 1 + (m − 1) · ICC
```

- `m` 是每组的观测数，组大小不等时近似用平均组大小。

假如有 100 个国家、每国 100 人，设计效应约为 1 + 99 × 0.059 ≈ 6.8。对国家层面的变量来说，看似一万个观测，信息量只相当于不到一千五百个独立观测；忽略嵌套，它们的标准误会被低估到应有大小的四成左右。

## 模型设定

**随机截距模型**：

```text
Y_ij = β_0 + β_1·X_ij + β_2·W_j + u_j + ε_ij
u_j ~ N(0, τ²),   ε_ij ~ N(0, σ²)
```

- `i` 是个体，`j` 是组；
- `X_ij` 是个体层的变量，比如受访者的教育；
- `W_j` 是组层的变量，比如国家的政体；
- `u_j` 是组 j 的随机截距，表示这一组整体比平均水平高或低多少；
- `β_0, β_1, β_2` 是固定部分的系数，读法和普通回归相同；
- `τ²` 和 `σ²` 是随机部分，即方差成分。

**随机斜率模型**，允许 X 的效应因组而异：

```text
Y_ij = β_0 + β_1·X_ij + β_2·W_j + β_3·X_ij·W_j + u_0j + u_1j·X_ij + ε_ij
(u_0j, u_1j) ~ N(0, Σ),   Σ = [ τ_0²  τ_01 ; τ_01  τ_1² ]
```

- `u_0j` 是截距的偏离，`u_1j` 是斜率的偏离，组 j 里 X 的效应是 `β_1 + β_3·W_j + u_1j`；
- `Σ` 是这两个偏离的协方差矩阵，`τ_0²` 是截距的组间方差；
- `τ_1²` 是斜率的组间方差；`τ_01` 是截距和斜率的协方差，比如基线高的国家，X 的效应是否也更大；
- `β_3` 是跨层交互：组层变量 W 能解释多少斜率上的差异。

很多社会学、教育学和比较政治的论文用分层写法，代入后就是上面的式子：

```text
第一层：Y_ij = b_0j + b_1j·X_ij + ε_ij
第二层：b_0j = γ_00 + γ_01·W_j + u_0j
        b_1j = γ_10 + γ_11·W_j + u_1j
```

- `b_0j`、`b_1j` 是组 j 自己的截距和斜率；
- `γ_00, γ_10, γ_01, γ_11` 依次对应上式的 `β_0, β_1, β_2, β_3`。

**广义多层模型**，结果是二值或计数：

```text
logit Pr(Y_ij = 1) = β_0 + β_1·X_ij + β_2·W_j + u_j,   u_j ~ N(0, τ²)
log E(Y_ij)        = β_0 + β_1·X_ij + β_2·W_j + u_j
```

- 第一行是随机截距 logit，R 里用 `glmer(..., family = binomial)`；
- 第二行是随机截距泊松或负二项，用 `glmer(..., family = poisson)` 或 `glmer.nb`，后者多估一个离散参数，适合起伏比泊松假设更大的事件次数；
- 二值模型里个体层的方差固定为 π²/3 ≈ 3.29，所以 ICC 写作 `τ² / (τ² + π²/3)`，是潜在倾向尺度上的比例。

**组内—组间分解**，用来放宽下面识别假设的第一条：

```text
Y_ij = β_0 + β_W·(X_ij − X̄_j) + β_B·X̄_j + β_2·W_j + u_j + ε_ij
```

- `X̄_j` 是组 j 内 X 的均值；
- `β_W` 是组内效应，在线性模型里等于固定效应估计；`β_B` 是组间效应；
- 两者差别很大时，说明组间关系里混有别的东西，不能只报一个合并的系数。

## 识别假设

多层模型是一种估计方法，不是因果识别设计。下面是它需要的条件，以及每一条不成立时的代价。

1. **随机效应和解释变量不相关**：`u_j` 和 X_ij、W_j 都不相关，这和随机效应模型的假设相同。不成立时，个体层变量的系数把组内关系和组间关系混在一起，有偏，偏向哪边事先不知道。补救是上面的组内—组间分解：把 X 的组均值放进去，组内系数就不再受这条假设影响；组层变量 W 的系数则仍然依赖它。
2. **随机效应近似正态**：在线性模型里这条大致不成立时，固定部分的系数通常仍然可靠，受影响较大的是每组的收缩预测值和方差成分；在广义模型里、组数又少时，影响更大。
3. **层级写对了**：漏掉一层，比如只放国家、不放国家里的地区，地区层的相关性就没被考虑，地区层变量的标准误偏小；把交叉分类当成嵌套，也会出同样的问题。
4. **该有的随机斜率要有**：X 的效应确实因组而异，模型却只放随机截距，X 的系数、尤其是跨层交互项的标准误会被严重低估。做跨层交互时，应当给其中的个体层变量加上随机斜率。
5. **组数足够多**：组间方差 τ² 实际上是靠组数而不是总观测数估出来的。只有十几个国家时，τ² 很不稳，常常被估成 0；国家层变量的标准误偏小，置信区间覆盖不足。
6. **扣除随机效应后，组内误差独立且同方差**：国家—年份数据里，相邻年份的误差往往还相关，只放国家随机截距不够。

**什么时候选多层模型，什么时候选固定效应**。固定效应不需要第 1 条，代价是估不出组层变量，观测少的组噪声大。多层模型能估组层变量、能做跨层交互、能给小组更稳的估计，代价是要相信第 1 条。经验上：

- 关心的是个体层变量的组内效应，又担心组间有看不见的混杂，用固定效应，或者用组内—组间分解；
- 关心组层变量、组间方差、斜率差异，或者组很多而每组观测很少，用多层模型；
- 组很少，比如十来个国家，多层模型的随机部分估不准，可以改用国家固定效应加少聚类时的推断方法，或者用两步法：先在每个国家内部分别回归，再把各国的系数对国家层变量回归，这样组层的有效样本量一目了然。

## 稳健性检验：做什么，为什么

每一项检验都对应上面的某条假设。读论文时，可以对照着看作者做了哪些、漏了哪些。

| 检验 | 检查哪条假设 | 怎么做，怎么看 |
|---|---|---|
| 空模型与 ICC | 有没有必要用多层模型 | 先估只有随机截距的模型，算 ICC。ICC 接近 0，分组对结果几乎没有影响；ICC 不小，忽略分组的标准误会被低估，按设计效应算一下低估多少 |
| 组内—组间分解，或与固定效应比较 | 随机效应和解释变量不相关 | 放入 X 的组均值，或者和固定效应模型比较 X 的系数。组内系数和组间系数接近，合并的系数可信；差别大时，以组内系数为准，组间系数另作解释 |
| 加入随机斜率 | 该有的随机斜率要有 | 给关键的个体层变量加随机斜率，看它和跨层交互项的标准误变多少。变大很多，说明原来的显著性是遗漏斜率差异造成的假象 |
| 似然比检验方差成分 | 某个随机斜率或某一层是否需要 | 比较有无这个方差成分的两个模型。方差不能小于 0，原假设落在参数空间的边界上，直接查卡方表得到的 p 值偏保守，检验单个方差时大约要减半 |
| REML 与小样本自由度修正 | 组数足够多 | 组少时用 REML 而不是最大似然估方差，固定部分用 Kenward–Roger 或 Satterthwaite 自由度做检验。修正后国家层变量不再显著，说明原结论靠的是过窄的置信区间 |
| 贝叶斯估计配弱信息先验 | 组数足够多 | 组很少时，最大似然常把 τ² 估成 0；给方差一个温和的先验，看固定部分的系数和区间是否稳定 |
| 逐个剔除组 | 结论不由一两个组主导 | 每次去掉一个国家重估，看国家层变量的系数是否稳定。组少时，单个异常国家就能决定组层系数 |
| 换优化器、重新缩放变量 | 估计是否真正收敛 | 出现收敛警告时，把连续变量中心化、标准化，换几种优化器重估。各优化器的估计一致，警告多半是虚警；不一致，就要简化随机部分 |
| 与聚类标准误的普通回归对比 | 模型设定整体是否可信 | 两种做法对个体层变量的估计应当大致一致；差别大时，说明随机效应的假设或层级结构有问题 |
| 残差和随机效应的诊断图 | 正态、同方差 | 画随机效应预测值的分位图、残差对拟合值的图。极端的组和明显的异方差要单独查 |

## 怎么读结果

R 的 lme4 输出分两块。

**Fixed effects** 是固定部分的系数，读法和普通回归相同。随机截距模型里的 β_1，是组内效应和组间效应的某种加权，权重取决于 τ²、σ² 和组大小；做了组内—组间分解时，分别读 β_W 和 β_B。lme4 本身不给 p 值，因为固定部分的自由度没有公认的算法；论文里的 p 值多半来自 lmerTest 包的 Satterthwaite 近似，或者直接把 t 值当作 z 值。

**Random effects** 是方差成分表，列出每一层的 Variance 和 Std.Dev.，有随机斜率时还有 Corr。方差成分要用标准差来读，单位和 Y 相同：

- 国家截距的标准差是 5，意味着各国的基线在平均值上下散布，约 95% 的国家落在平均值 ±10 之内；
- X 的固定系数是 2、随机斜率的标准差是 1.5，意味着约 95% 的国家里 X 的效应在 2 ± 2.9 之间，即从 −0.9 到 4.9；按正态分布算，约 9% 的国家效应为负。只报 2 而不报 1.5，读者会严重高估这个效应的普遍性；
- 截距和斜率的相关系数是 −0.6，意味着基线高的国家，X 的效应往往更小，可能是天花板效应；
- 加入国家层变量 W 前后，国家截距的方差从 25 降到 15，可以说 W 解释了约 40% 的国家间差异；
- Residual 一行是组内方差 σ²，和截距方差一起可以算出 ICC。

广义多层模型的系数是**条件效应**：给定同一个随机效应，也就是在同一个国家内部比较时 X 的作用。logit 模型里，条件效应的绝对值比把所有国家平均起来的总体效应更大，组间方差越大差得越多。它和普通 logit 或广义估计方程 GEE 的系数不能直接比较。

读的时候可以这样说：在控制个人特征后，国家层面的 W 每提高一个单位，Y 平均高 β_2；Y 的差异中约有 ICC 这么大的比例来自国家之间；X 的效应平均为 β_1，但国家之间的标准差为 τ_1，在一部分国家里方向相反。

## 常见陷阱

- **组数太少却大谈国家层效应**：二三十个国家的跨国调查很常见，个人观测数以万计，但国家层变量的有效样本只有二三十。
- **跨层交互不加随机斜率**：交互项的标准误被低估，显著性靠不住。
- **忽略随机效应和解释变量的相关**：把混有组间差异的系数当成个体层效应来报告。
- **奇异拟合**：lme4 提示 `boundary (singular) fit`，意思是某个方差被估成 0，或者某个相关系数被估成 ±1。这说明随机部分对数据来说太复杂，常见于组少而随机斜率多的时候。可以去掉截距和斜率之间的相关，即在公式里用 `||`，或者去掉方差最小的斜率。
- **用 REML 似然比较固定部分不同的模型**：REML 似然只能比较固定部分相同、随机部分不同的模型。lme4 的 `anova()` 会自动改用最大似然重新拟合，手算似然比时要自己注意。
- **把收缩预测值当作数据再回归**：用 `ranef()` 取出各组的随机效应，再拿去和别的变量做第二步回归，会把收缩和估计误差一起带进去，标准误也不对。应当把那个变量直接放进模型。
- **把条件效应和总体平均效应混为一谈**：尤其在比较多层 logit 和普通 logit 的系数时。

**收敛警告**。lme4 常见三种提示：`Model failed to converge`，后面跟着 `max|grad|` 的数值，说明优化器停下的地方梯度还不够小；`Model is nearly unidentifiable: very large eigenvalue`，常见于变量尺度相差悬殊，比如人口以人计而比例以小数计；以及上面的奇异拟合。处理的顺序是：

1. 先把连续变量中心化、标准化，这一步常常就能消除警告；
2. 换优化器，比如 `glmerControl(optimizer = "bobyqa")`，或者用 `allFit()` 把几种优化器都跑一遍，比较固定系数和方差估计；
3. 各优化器的结果在小数点后两三位一致，警告多半是虚警，可以在论文里说明后照常报告；不一致，就要简化随机部分；
4. 不要一见警告就删掉随机斜率，也不要视而不见。前者可能删掉了真实存在的斜率差异，后者可能报告了没收敛的估计。

`glmer` 默认用拉普拉斯近似计算似然；只有一个随机截距时，可以把 `nAGQ` 设得大于 1，用更精确的积分检查结果是否稳定。Stata 的 `melogit` 默认用 7 个积分点，可以用 `intpoints()` 增加。复现时还要注意，lme4 不同版本的默认优化器和收敛判据有过调整，同样的代码在新版本上警告出现或消失、估计在末几位不同，都属正常。

## 代码写法

R，常用 lme4，配 lmerTest 取得 p 值：

```r
library(lme4)
library(lmerTest)   # 载入后 lmer 的 summary 会给出 Satterthwaite 自由度和 p 值

# 空模型：只有国家随机截距，用来算 ICC
m0 <- lmer(y ~ 1 + (1 | country), data = df)
vc <- as.data.frame(VarCorr(m0))
vc$vcov[1] / sum(vc$vcov)          # ICC = 国家方差 / 总方差

# 随机截距：个人层变量 x，国家层变量 w
m1 <- lmer(y ~ x + w + (1 | country), data = df)

# 随机斜率加跨层交互：x 的效应因国家而异，w 解释其中一部分
m2 <- lmer(y ~ x * w + (1 + x | country), data = df)

# 截距和斜率互不相关的简化版本
m3 <- lmer(y ~ x * w + (1 + x || country), data = df)

summary(m2)
VarCorr(m2)        # 方差成分
ranef(m2)          # 各国的偏离，即收缩后的预测值
isSingular(m2)     # 是否有方差估计落在边界

# 嵌套与交叉分类
m4 <- lmer(y ~ x + (1 | country/region), data = df)          # 地区嵌套在国家里
m5 <- lmer(y ~ x + (1 | country) + (1 | year), data = df)    # 国家与年份交叉

# 组内—组间分解
df$x_mean <- ave(df$x, df$country)
df$x_dev  <- df$x - df$x_mean

            control = glmerControl(optimizer = "bobyqa"))
```

Python，statsmodels 主要支持线性多层模型，广义多层模型作者多半在 R 或 Stata 里做：

```python
import statsmodels.formula.api as smf
# 随机截距，默认用 REML
m1 = smf.mixedlm("y ~ x + w", data=df, groups=df["country"]).fit()
# 随机截距加 x 的随机斜率
m2 = smf.mixedlm("y ~ x * w", data=df, groups=df["country"], re_formula="~x").fit()
print(m2.summary())
```

在作者代码里认多层模型，看这几处：公式里带竖线的括号，比如 `(1 | country)`、`(1 + x | country)`、`(1 | country/region)`、双竖线 `||`；`lmer`、`glmer`、`glmer.nb`、`glmmTMB`，以及用同样括号语法的 `brms::brm` 和 `blmer`；Stata 的 `mixed`、`melogit`、`mepoisson`、`menbreg`，旧版本的 `xtmixed`、`xtmelogit`，以及命令里的 `|| country:`；Python 的 `mixedlm`、`groups=`、`re_formula=`。Stata 的 `xtreg, re` 也是随机截距模型，只是用广义最小二乘估计。

## 适用的问题

处理不是任意分配的，而是由一条明文规则决定：某个连续的分数一旦越过门槛就受处理，没越过就不受。这个分数叫运行变量，也叫驱动变量。比如：

- 两名候选人的得票率之差越过 0，前者当选；
- 政党的全国得票率越过法定门槛，比如 5%，才能进入议会分得席位；
- 人口超过某个数字的市镇，必须改用另一种选举制度，或者设更大的议会；
- 人均收入低于某条线的国家，才有资格获得优惠贷款或援助。

我们想问：越过门槛这件事本身带来了什么后果？离门槛很远的单位彼此差别太大，没法直接比；但得票 50.1% 和 49.9% 的候选人、人口 9,990 和 10,010 的市镇，除了一个越过门槛、一个没越过，其他方面应当差不多。断点回归利用的就是门槛附近这种局部的可比性。

## 核心思想

把结果对运行变量画成散点图。如果处理没有作用，结果应当随运行变量平滑变化，经过门槛时不会突然断开；如果曲线在门槛处断开、出现一个台阶，台阶的高度就是处理的效果。

按门槛对处理的决定程度，分两种情形：

- **精确断点**：越过门槛就一定受处理，没越过就一定不受，受处理的概率在门槛处从 0 跳到 1。选举是典型的精确断点：票数领先就当选。
- **模糊断点**：越过门槛只让受处理的概率跳了一截，跳不到 1。援助资格按收入划线，但实际拿没拿到援助还要看谈判和其他条件。这时门槛只是一种推动，要用工具变量的逻辑把效果换算出来。

一个模糊断点的数字例子：

| | 紧挨门槛左侧 | 紧挨门槛右侧 | 跳跃 |
|---|---|---|---|
| 实际获得援助的比例 | 0.20 | 0.70 | +0.50 |
| 某项发展指标的均值 | 40 | 43 | +3 |
| 模糊断点估计值 | | | 3 ÷ 0.50 = 6 |

越过门槛让获得援助的比例多了 50 个百分点，指标平均多了 3。这 3 全部来自因为越线才拿到援助的那一半国家，所以把 3 除以 0.5，得到这部分国家的效果 6。精确断点是分母等于 1 的特例。

断点回归的效果只在门槛这一个点上识别。门槛上恰好落着的观测很少，只能从两侧往门槛逼近：用多宽的数据窗口、用什么形状的曲线去逼近，是这个方法几乎所有技术讨论的来源。

## 模型设定

**估计对象**，以精确断点为例：

```text
τ = lim_{x↓c} E[Y_i | X_i = x] − lim_{x↑c} E[Y_i | X_i = x] = E[Y_i(1) − Y_i(0) | X_i = c]
```

- `X_i`：运行变量；`c`：门槛；
- `x↓c`、`x↑c`：分别从右侧和左侧逼近门槛，两个极限之差就是图上台阶的高度；
- `Y_i(1)`、`Y_i(0)`：单位 i 受处理和不受处理时的潜在结果；
- 第二个等号要靠下文的连续性假设才成立：它把一个看得见的跳跃，解释成恰好位于门槛上的单位的平均处理效应。

**局部线性回归**，只用门槛附近带宽以内的观测，两侧各拟合一条直线：

```text
Y_i = α + τ·Z_i + β₁·(X_i − c) + β₂·Z_i·(X_i − c) + ε_i，   只用 |X_i − c| ≤ h 的观测
权重 K_i = 1 − |X_i − c| / h
```

- `Z_i = 1[X_i ≥ c]`：越过门槛取 1，精确断点下它就是处理变量；
- `X_i − c`：中心化后的运行变量，让截距落在门槛上；
- `Z_i·(X_i − c)`：允许门槛两侧的斜率不同；
- `τ`：两条直线在门槛处的高度差，就是效果的估计值；
- `h`：带宽，决定用门槛两侧多宽的窗口；
- `K_i`：三角核权重，离门槛越近权重越大，到带宽边缘降为 0。

**模糊断点**，把越线当作工具变量：

```text
第一阶段：D_i = γ₀ + π·Z_i + γ₁·(X_i − c) + γ₂·Z_i·(X_i − c) + u_i
τ_F = τ_Y / π
```

- `D_i`：实际是否受处理；
- `π`：受处理概率在门槛处的跳跃；
- `τ_Y`：结果在门槛处的跳跃，即上一段回归里的 τ；
- 在同一带宽和核权重下，用 `Z_i` 作 `D_i` 的工具变量做两阶段最小二乘，得到的正是这个比值。

**带宽怎么选**。带宽越宽，样本越多，方差越小；但离门槛远的点会把直线拉离门槛处真实的曲线，偏差越大。MSE 最优带宽在偏差和方差之间取平衡，Imbens 和 Kalyanaraman、Calonico、Cattaneo 和 Titiunik 先后给出了数据驱动的选法。麻烦在于：在 MSE 最优带宽下，偏差与标准误同阶，而传统置信区间默认偏差为零，于是区间偏窄、覆盖率不足。Calonico、Cattaneo 和 Titiunik 的稳健偏差校正推断分两步解决：先用高一阶的局部多项式估计这部分偏差并扣掉；再在标准误里计入偏差估计本身带来的额外不确定性。实际报告时，点估计通常用传统估计值，置信区间和 p 值用稳健偏差校正的那一行。另一个选择是专为置信区间覆盖率优化的 CER 最优带宽，它比 MSE 最优带宽窄。

**为什么不用高阶全局多项式**。早期研究常用全部样本，把运行变量的三次、四次项放进回归。Gelman 和 Imbens 给出三条理由反对这种做法：

1. 全局多项式对门槛处的估计，等于对全部观测结果的加权平均，而离门槛很远的观测可能拿到很大、甚至正负来回变化的权重，门槛处的值被远处的数据左右；
2. 结果对多项式阶数很敏感，三次和四次可能给出差别很大的答案，而选阶数又没有可靠的依据；
3. 置信区间的覆盖率偏低，容易得出虚假的显著。

所以现在的标准做法是局部线性或局部二次回归，配三角核和数据驱动的带宽。全局多项式只适合在画图时当作视觉辅助：`rdplot` 默认在两侧各画一条四次多项式拟合线，不能拿它当估计值。

## 识别假设

1. **潜在结果在门槛处连续**：没有处理时，结果的条件期望在门槛两侧本应平滑衔接；受处理时的潜在结果也一样。这是断点回归唯一的核心假设。它说的是看不见的反事实，无法直接检验，下面的检验都只是间接证据。
2. **单位不能精确操纵运行变量**：Lee 的论证是，只要单位对自己的运行变量只有不精确的控制，最后落在门槛哪一侧就带有随机成分，门槛附近就近似一场随机实验。如果单位能精确地把自己推过门槛，比如政府把统计数字报成恰好够资格，门槛两侧的单位就会在动机和能力上系统地不同，连续性随之破坏。
3. **门槛上没有别的东西同时变化**：如果同一个人口门槛还决定了地方官员的工资，门槛处的跳跃就是两项规定合起来的效果，分不开。制度性门槛常常捆着好几项规定，要逐条查法规。
4. **模糊断点的额外要求**：第一阶段跳跃明显不为零；越线只通过改变是否受处理来影响结果，即排除性约束；没有单位因为越线反而不接受处理，即单调性。满足这些条件时，估计的是门槛处顺从者的局部平均处理效应。
5. **运行变量测得准，门槛已知**：运行变量有测量误差或被粗略取整时，单位被分错了边，台阶会被抹平。运行变量只取少数几个值时，比如按年记的年龄，局部多项式的逼近不再可靠，需要专门的推断方法。

**险胜选举设计及其争议**。政治学里用得最多的断点回归，是以得票率差距为运行变量、以 0 为门槛的险胜选举设计：以 50.1% 对 49.9% 胜出，被看作近乎随机的结果。它被用来估计在任优势、执政党派对政策的影响，以及选出某类政治人物的后果，比如某一派政党上台是否改变军费、对外援助或贸易政策。围绕它有三类批评：

- **险胜并不总是随机**。Caughey 和 Sekhon 发现，战后美国众议院的险胜选举里，在任一方赢的比例明显高于一半，前定协变量在门槛两侧也不平衡，说明双方对结果并非只有不精确的控制，资源和信息占优的一方可能把自己推过了门槛。Eggers 等人检查了多个国家四万多场险胜选举，没有发现这种普遍的不平衡，美国众议院更像个例。读论文时要看作者是否对自己的选举样本做了平衡和密度检验：别人的样本没问题，不等于这个样本没问题。
- **估计的是谁的效果**。de la Cuesta 和 Imai 强调，险胜设计识别的只是势均力敌的选举中赢下选举的效果，推到一般选举需要额外的论证。Lee 的经典设计估计的是政党本次险胜对它下次得票的影响，即政党层面的在任优势，不等于候选人个人的在任优势。
- **比较候选人特征时的捆绑问题**。比较女性险胜男性和男性险胜女性的选区，随机的是谁赢，不是性别本身。Marshall 指出，一场选举之所以打得这么接近，往往是因为在某方面吃亏的候选人在别的方面有补偿；于是两侧的胜选者在其他特征上系统地不同，估计出来的是选出带有这一特征、以及与之捆绑的其他特征的候选人的效果。

## 稳健性检验：做什么，为什么

每一项检验都对应上面的某条假设。读论文时，可以对照着看作者做了哪些、漏了哪些。

| 检验 | 检查哪条假设 | 怎么做，怎么看 |
|---|---|---|
| 断点图 | 连续性、函数形式 | 用 `rdplot` 画分箱均值和两侧拟合线。门槛处应当有清楚的台阶，门槛以外不该出现同样大的跳动；图上看不出台阶，回归里的显著多半来自设定 |
| 密度检验 | 不能精确操纵 | 用 McCrary 检验或 Cattaneo、Jansson 和 Ma 的 `rddensity`，检查运行变量的密度在门槛处是否断开。门槛右侧的观测异常地多，说明有人把自己推过了线，门槛附近已经不像随机实验 |
| 前定协变量平衡 | 连续性 | 把处理之前就确定的变量，比如上届得票率、人口、所在地区，当作结果跑同样的断点回归。它们不应有跳跃；有跳跃说明两侧单位本来就不同，结果的跳跃可能来自这些差别 |
| 滞后结果 | 连续性 | 用处理之前一期的结果作因变量。处理不可能影响过去；过去的结果也在门槛处跳，说明跳跃不是处理造成的 |
| 带宽敏感性 | 局部线性逼近是否够好 | 在 MSE 最优带宽的一半、两倍以及 CER 最优带宽下重估。估计值应当大体稳定；只在某一个带宽下显著，就是在挑带宽 |
| 多项式阶数 | 函数形式 | 对比局部线性和局部二次。差别很大，说明门槛附近曲线弯得厉害，或者带宽内数据太少 |
| 稳健偏差校正推断 | 推断是否有效 | 在 MSE 最优带宽下报告稳健偏差校正的置信区间，不报传统区间。这个带宽有意留下了与标准误同阶的偏差，传统区间会偏窄 |
| 安慰剂门槛 | 跳跃只出现在真门槛 | 在门槛以外的位置假设一个门槛，只用同一侧的数据重估。假门槛上应当没有效果；到处都能估出跳跃，说明结果曲线本身噪声大或弯曲，真门槛处的跳跃也不可信 |
| 甜甜圈断点 | 紧贴门槛处的操纵或堆积 | 去掉离门槛最近的一小段观测再估计。最贴近门槛的点最容易被操纵或取整；去掉它们后效果大变，说明结论靠这几个可疑的点撑着 |
| 加入协变量 | 两侧可比、估计精度 | 把前定协变量放进 `covs`。连续性成立时，加协变量只应缩小标准误，不应明显改变点估计；点估计大变，说明两侧不平衡 |
| 第一阶段 | 模糊断点中工具变量的相关性 | 单独报告受处理概率在门槛处的跳跃及其显著性。跳跃很小时比值极不稳定，相当于弱工具变量 |

需要强调一点：密度和协变量检验通过，只说明没有看到违反连续性的迹象，并不证明连续性成立；带宽内样本少的时候，这些检验的统计功效同样很低。

## 怎么读结果

- **τ 的含义**：运行变量恰好等于门槛的单位，受处理与不受处理的平均差别。离门槛远的单位效果可能完全不同：险胜选举的效果属于竞争激烈的选区，不能直接推到安全选区。
- **模糊断点**：估计的是门槛处顺从者的效果，范围更窄，只针对那些因为越线才改变处理状态的单位。
- **`rdrobust` 的输出**：带宽 h 和用于偏差校正的 b；两侧的有效样本量，即带宽内实际参与估计的观测数；`Conventional` 一行的点估计和标准误；`Robust` 一行的置信区间和 p 值。全样本可能有几万个观测，带宽内只剩几百个，结论只建立在这几百个单位上。
- **表格里要找的信息**：核函数、多项式阶数、带宽及其选法、两侧有效样本量、稳健置信区间、标准误是否聚类。

读的时候可以这样说：在 MSE 最优带宽内、两侧各约 N 个观测上，用局部线性回归和三角核估计，险胜使该党下一届当选的概率提高 τ 个百分点，稳健置信区间为 [a, b]；运行变量的密度和前定协变量在门槛处都没有明显跳跃。

## 常见陷阱

- **用全部样本加高阶多项式估计**：门槛处的估计被远处数据左右，置信区间偏窄。
- **在 MSE 最优带宽下报传统置信区间**：显著性被高估。
- **挑带宽**：试很多带宽，只报显著的那个。
- **把门槛处的效果当成普遍效果**：断点回归内部效度高，外部效度窄。
- **控制了门槛之后才确定的变量**：比如研究当选的影响，却控制了当选后的支出，这是坏控制。
- **安慰剂门槛跨过了真门槛**：用两侧数据估假门槛，真跳跃会混进来，应当只用一侧的数据。
- **运行变量有堆积**：分数和统计数字常常集中在整数或整十上，堆积点恰好落在门槛附近时，局部估计会被这些点主导，要做甜甜圈检验。
- **多个门槛混在一起**：不同单位面对不同门槛时，先把运行变量减去各自的门槛再合并；合并后的估计是各门槛效果的加权平均。
- **把不显著读成没有效果**：带宽内样本少，置信区间往往很宽。

## 代码写法

R，常用 Cattaneo 等人维护的 rdrobust 和 rddensity：

```r
library(rdrobust)
library(rddensity)
# y 是结果，x 是运行变量，门槛 c = 0；d 是实际是否受处理

# 断点图：分箱均值加两侧拟合线，只用来看图
rdplot(y = df$y, x = df$x, c = 0)

# 精确断点：默认局部线性、三角核、MSE 最优带宽，输出含稳健偏差校正的置信区间
est <- rdrobust(y = df$y, x = df$x, c = 0)
summary(est)

# 模糊断点
summary(rdrobust(y = df$y, x = df$x, c = 0, fuzzy = df$d))

# 加入前定协变量、按选区聚类
summary(rdrobust(y = df$y, x = df$x, c = 0,
                 covs = cbind(df$z1, df$z2), cluster = df$district))

# 列出各种带宽，包括 MSE 最优和 CER 最优
summary(rdbwselect(y = df$y, x = df$x, c = 0, all = TRUE))

# 密度检验
summary(rddensity(X = df$x, c = 0))

# 协变量平衡：前定协变量当结果，应当没有跳跃
summary(rdrobust(y = df$z1, x = df$x, c = 0))

# 甜甜圈：去掉离门槛 0.5 以内的观测
dn <- subset(df, abs(x) > 0.5)
summary(rdrobust(y = dn$y, x = dn$x, c = 0))

# 安慰剂门槛：只用门槛右侧的数据，假设门槛在 x = 5
pr <- subset(df, x >= 0)
summary(rdrobust(y = pr$y, x = pr$x, c = 5))
```

Stata：

```stata
* 断点图
rdplot y x, c(0)
* 精确断点
rdrobust y x, c(0)
* 模糊断点，加协变量、按选区聚类
rdrobust y x, c(0) fuzzy(d) covs(z1 z2) vce(cluster district)
* 各种带宽
rdbwselect y x, c(0) all
* 密度检验
rddensity x, c(0)
* 甜甜圈
rdrobust y x if abs(x) > 0.5, c(0)
```

Python：

```python
from rdrobust import rdrobust
# 精确断点
print(rdrobust(y=df["y"], x=df["x"], c=0))
# 模糊断点
print(rdrobust(y=df["y"], x=df["x"], c=0, fuzzy=df["d"]))
```

在作者代码里认断点回归，看这几处：`rdrobust`、`rdplot`、`rdbwselect`、`rddensity`、`rdrandinf` 这一族命令，以及较早的 `DCdensity`；手写时的特征是先把运行变量减去门槛，再放进越线哑变量 `x >= c` 与中心化运行变量的交互项，同时用 `abs(x - c) <= h` 限制样本、用 `1 - abs(x - c)/h` 作权重；全样本里一起放了 `x`、`x^2`、`x^3`、`x^4` 或者 `poly(x, 4)`，就是不推荐的全局多项式写法；模糊断点则表现为以越线哑变量为工具变量的两阶段回归。

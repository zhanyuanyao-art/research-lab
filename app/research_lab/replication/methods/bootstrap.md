## 适用的问题

自助法回答的不是「效果是多少」，而是「这个估计有多不确定」。它在下面几种情况下有用：

- **统计量没有现成的标准误公式**：中位数、两个系数之比、中介分析里的间接效应、非线性模型里的预测概率之差、由模拟得出的实质效应。
- **公式有，但它依赖的假设可疑**：样本小、分布偏，或者聚类很少。
- **估计分两步或多步**：第一步从数据里估出一个量，比如从联合国大会投票里估出各国的理想点、从文本里估出一个立场分数、用一个预测模型估出某种倾向；第二步再把它当作解释变量。公式标准误把第一步的结果当作确知的，忽略了它的误差。
- **数据有复杂的依赖**：面板里同一国家各年相关，时间序列里相邻时期相关。

## 核心思想

标准误回答的是一个假想的问题：如果能从总体里再抽一次样本、再估一次，估计值会变多少？我们不可能真的回到总体去抽，但样本本身是总体的一个缩影。自助法的思路是：**把样本当作总体，从中有放回地抽取同样大小的新样本**，在每个新样本上把估计重做一遍，看估计值怎么变。

一个极小的数字例子。样本是 5 个数：1、3、4、8、14，中位数是 4。有放回地抽 5 次，组成一个自助样本，重复几次：

| 自助样本 | 抽到的值 | 中位数 |
|---|---|---|
| 第 1 个 | 3、1、14、3、8 | 3 |
| 第 2 个 | 8、4、1、14、8 | 8 |
| 第 3 个 | 1、4、3、1、4 | 3 |
| 第 4 个 | 14、3、8、4、14 | 8 |

有放回意味着同一个值可以被抽中多次，有的值一次也没抽中。平均来说，一个自助样本只包含原样本中约 63% 的不同观测。重复 B 次，比如 1000 次，得到 1000 个中位数：它们的标准差就是中位数的自助标准误；把它们从小到大排好，第 25 个和第 975 个附近之间，就是一个 95% 的百分位区间。

5 个观测只是为了演示。样本这么小，经验分布离总体太远，自助法本身也不可靠；而且中位数是个不光滑的统计量，小样本里它的自助分布只取寥寥几个值，上表四次就只出现了 3 和 8。

贯穿全章的一条原则：**重抽样要模仿原来的抽样过程**。原数据里哪一层是彼此独立的，就抽哪一层；原估计做了哪些依赖数据的步骤，每个自助样本就重做哪些步骤。后面的块自助、聚类自助、两步估计的自助，都是这条原则的应用。

## 模型设定

**基本步骤**：

```text
θ̂ = s(x_1, …, x_n)
对 b = 1, …, B：
    从 {x_1, …, x_n} 中有放回、等概率地抽 n 个，得到 x*_1, …, x*_n
    θ̂*_b = s(x*_1, …, x*_n)
SE_boot = √( Σ_b (θ̂*_b − θ̄*)² / (B − 1) )
```

- `s(·)` 是从数据算出估计值的整个过程，可以是一个中位数，也可以是一整套多步估计；
- `θ̂` 是原样本上的估计值，`θ̂*_b` 是第 b 个自助样本上的估计值；
- `θ̄*` 是 B 个自助估计的均值，`B` 是重复次数。

**置信区间的几种算法**。下面 `θ̂*_(q)` 表示 B 个自助估计的 q 分位数，α 是显著性水平，95% 区间时 α = 0.05。

正态区间：

```text
θ̂ ± z_(1−α/2) · SE_boot
```

- `z_(1−α/2)` 是标准正态分位数，95% 时为 1.96；
- 只用自助法估标准误，区间仍然假定估计量近似正态。

百分位区间：

```text
[ θ̂*_(α/2),  θ̂*_(1−α/2) ]
```

- 直接取自助分布两端的分位数。简单直观，对单调变换保持不变：对数尺度上的区间取指数，就是原尺度上的区间。
- 它暗含的假定是：存在某个变换，能让估计量的分布对称且以真值为中心。自助分布偏斜，或者整体偏离 θ̂ 时，覆盖率会打折扣。

基本区间，也叫反向百分位区间：

```text
[ 2θ̂ − θ̂*_(1−α/2),  2θ̂ − θ̂*_(α/2) ]
```

- 把自助分布相对 θ̂ 的偏离反过来用。R 的 boot.ci 会报这一种，标为 basic。

自助 t 区间：

```text
t*_b = (θ̂*_b − θ̂) / SE*_b
[ θ̂ − t*_(1−α/2) · SE,  θ̂ − t*_(α/2) · SE ]
```

- `SE*_b` 是第 b 个自助样本内部算出的标准误，`SE` 是原样本的标准误；
- `t*_(q)` 是 B 个 t*_b 的 q 分位数，用它代替查表的 1.96；
- 它不直接对估计值做自助，而是对标准化后的 t 统计量做自助，理论精度比百分位区间高一阶；
- 代价是每个自助样本里都要有可靠的标准误。SE*_b 偶尔很小时，t*_b 会出现极端值，区间变得又宽又乱。

偏差校正加速区间，简称 BCa：

```text
ẑ_0 = Φ⁻¹( #{θ̂*_b < θ̂} / B )
â   = Σ_i (θ̂_(·) − θ̂_(i))³ / { 6 · [ Σ_i (θ̂_(·) − θ̂_(i))² ]^(3/2) }
α_1 = Φ( ẑ_0 + (ẑ_0 + z_(α/2))   / (1 − â·(ẑ_0 + z_(α/2))) )
α_2 = Φ( ẑ_0 + (ẑ_0 + z_(1−α/2)) / (1 − â·(ẑ_0 + z_(1−α/2))) )
区间 = [ θ̂*_(α_1),  θ̂*_(α_2) ]
```

- `Φ` 是标准正态分布函数，`z_q` 是它的 q 分位数；
- `ẑ_0` 是偏差校正：自助估计里有多大比例小于原估计。正好一半时 ẑ_0 = 0，说明自助分布以 θ̂ 为中心；
- `θ̂_(i)` 是去掉第 i 个观测后的估计，即刀切法估计，`θ̂_(·)` 是它们的均值；`â` 是加速常数，衡量估计量的标准误随真值变化的快慢，反映分布的偏斜；
- `α_1`、`α_2` 是调整后的分位点，区间不再取自助分布的 2.5% 和 97.5% 分位数，而是取 α_1 和 α_2 分位数；
- ẑ_0 和 â 都为 0 时，α_1 = α/2、α_2 = 1 − α/2，BCa 就退回百分位区间。

BCa 保留了百分位区间对变换不变的好处，又修正了偏差和偏斜，理论精度和自助 t 相当，通常是首选。代价是要多算 n 次刀切法估计，而且它常常要用更靠尾部的分位数，需要更多的重复次数。

**依赖数据的重抽样**：

- **块自助**：时间序列里相邻时期相关，逐期抽会打散这种相关。改为抽取连续的一段，比如每次抽连续 5 年，拼成新序列。块要足够长，才能保留主要的相关；又不能太长，否则块太少，自助分布太粗。
- **聚类自助**，也叫成对聚类自助：面板或多层数据里，抽的是整个国家，连同它所有年份的观测一起进入自助样本。这和聚类稳健标准误的思路一致：国家之间独立，国家内部任意相关。
- **野聚类自助**：不重抽观测，而是保留 X 不动，把每个聚类的残差整体乘以一个随机权重，再加回拟合值，生成新的 Y：

```text
Y*_ig = X_ig′β̃ + w*_g · ũ_ig
```

- `g` 是聚类，`i` 是聚类内的观测；
- `w*_g` 是同一聚类共用的随机权重，常用 Rademacher 权重，以各一半的概率取 +1 或 −1；
- `β̃`、`ũ_ig` 通常是**施加了原假设**之后的估计和残差，比如在 X 的系数等于 0 的约束下估计；
- 对每个自助样本算 t 统计量，看原样本的 t 在这些自助 t 里排在什么位置，得到 p 值；置信区间由检验反推。

**为什么少聚类要用野聚类自助**。聚类稳健标准误的理论依据是聚类数趋于无穷。只有十几二十个聚类时，它系统性地偏小，t 检验拒绝原假设的频率远高于名义水平。成对聚类自助这时也有问题：处理变量只在少数聚类里变化时，许多自助样本里根本没有受处理的聚类，估计都做不出来。野聚类自助保留了原来的 X，不会出现这种情况；对 t 统计量做自助，又带来更好的小样本精度。还有两个细节：

- Rademacher 权重下，G 个聚类只有 2^G 种不同的组合。聚类少于十来个时，组合太少，p 值只能取寥寥几个值，这时改用 Webb 的六点权重。
- 受处理的聚类只有一两个时，野聚类自助也会失灵，p 值不可信，只能如实说明推断的局限。

**两步估计的自助**。第二步的解释变量是第一步估出来的，叫生成的解释变量。公式标准误只反映第二步的不确定性，把第一步的估计值当作没有误差的数据，标准误偏小。自助法把两步当作一个整体：

```text
对 b = 1, …, B：
    重抽样本，在自助样本上重新估计第一步，得到新的生成变量
    用这个新的生成变量估计第二步，记下 θ̂*_b
```

- 两步必须用同一个自助样本；
- 第一步用的是另一份数据时，比如用全部唱名投票记录估理想点，那份数据也要按它自己的独立单位重抽；
- 第一步是贝叶斯估计时，也可以从第一步的后验中反复抽一组生成变量，各跑一次第二步，再把各次结果合起来，思路相同。

**重复次数**。自助估计本身有蒙特卡洛误差，B 越大越小：

```text
自助 p 值的蒙特卡洛标准误 ≈ √( p · (1 − p) / B )
自助标准误的相对蒙特卡洛误差 ≈ 1 / √(2B)
```

- `p` 是自助得到的 p 值，`B` 是重复次数；
- 第二个式子在估计量近似正态时成立。

算一下：p = 0.04、B = 999 时，p 值本身的蒙特卡洛标准误约为 0.006，换一个种子，p 值落在 0.028 到 0.052 之间都不奇怪，0.05 这条线两边都有可能。B = 1000 时，标准误本身有约 2% 的随机波动，0.150 换个种子变成 0.147 或 0.153 都正常。经验上：只估标准误，几百次就够；百分位区间、BCa 和 p 值要 1000 次以上；结论落在显著性边缘时要 9999 次甚至更多。做自助检验时常选 999、9999 这样的次数，使 `(B + 1)·α` 为整数，p 值的计算更干净。

**种子与可复现**。自助法用的是伪随机数，设定同一个种子，就得到同一串随机数。复现别人的自助结果时，最后一位对不上很常见，原因通常是下面几种之一：

- 作者没有设种子，或者种子设在了和你不同的位置：载入数据之前还是之后，循环之内还是之外，中间还有没有别的命令消耗了随机数；
- 随机数算法变了。R 从 3.6.0 起改变了 `sample()` 的默认抽样方法，重现旧结果要用 `RNGkind(sample.kind = "Rounding")`；Stata 从 14 版起默认的随机数生成器换成了 64 位梅森旋转，重现旧结果要用 `set rng kiss32` 或版本控制；
- 数据的行序不同。同一个种子抽到的是「第 17 行」，行序一变，第 17 行就是另一个观测。Stata 的 `sort` 遇到并列值时顺序是随机的，除非加 `stable` 选项；
- 并行计算。每个进程各有一串随机数，结果和进程数、任务分块的方式有关；
- 失败的重复。有些自助样本上模型不收敛或无法估计，软件默默丢掉它们，丢掉几个取决于随机数；
- 分位数的算法。从 1000 个数里取 2.5% 分位数，不同软件的插值方式不同。

这些差别都应当落在上面算出的蒙特卡洛误差之内。差别远大于蒙特卡洛误差，或者结论在显著与不显著之间翻转，就不是随机性的问题，要回头查数据和设定。

## 识别假设

自助法不是因果识别设计，它只回答估计有多不确定。要把这个问题答对，需要以下条件：

1. **重抽的单位彼此独立**：自助法把被抽的单位当作独立同分布。抽的是国家—年份，而同一国家各年相关，就等于忽略了序列相关，标准误偏小，和不聚类的公式标准误犯的是同一个错。
2. **统计量足够光滑**：均值、回归系数这类估计量没有问题。样本最大值或最小值、落在参数边界上的估计，比如被估成 0 的方差，以及最近邻匹配估计量，它们的自助分布不能代表真实的抽样分布，区间的覆盖率会出错。Abadie 和 Imbens 证明了标准的自助法对最近邻匹配估计量是失效的。
3. **样本足够大**：经验分布要能代表总体。样本或聚类很少时，自助分布往往太窄，置信区间偏短。
4. **重抽样复制了整个估计过程**：变量标准化、缺失值插补、模型选择、第一步估计，凡是依赖数据的步骤都要在每个自助样本上重做。只重做最后一步，被遗漏步骤的不确定性就不在标准误里。
5. **自助法不修正偏误**：它衡量的是估计值在偏误附近的波动。原估计有偏，比如弱工具下的两阶段最小二乘，自助法给出的是一个以有偏值为中心的区间。自助法也能估计偏误的大小，但用它去校正估计值会增大方差，一般只用于诊断。
6. **重复次数足够**：否则蒙特卡洛误差会混进结论。

## 稳健性检验：做什么，为什么

每一项检验都对应上面的某条假设。读论文时，可以对照着看作者做了哪些、漏了哪些。

| 检验 | 检查哪条假设 | 怎么做，怎么看 |
|---|---|---|
| 换种子、增加重复次数 | 重复次数足够 | 用另一个种子，或者把 B 扩大十倍重跑。估计和区间的变化应当在蒙特卡洛误差之内；结论随种子翻转，说明 B 不够，或者结论本来就落在边缘 |
| 画自助分布的直方图 | 统计量足够光滑 | 正常的自助分布是单峰、大致平滑的。出现多峰、少数几个尖峰或极端离群值，说明估计不稳，或者某些自助样本里模型几乎无法识别 |
| 统计失败的重复 | 每个自助样本都能完成估计 | 记录有多少次不收敛或被丢弃。被丢掉的多半是困难的样本，丢多了，剩下的分布会显得过于乐观 |
| 比较正态、百分位、BCa 区间 | 抽样分布是否对称、以真值为中心 | 几种区间接近，说明近似正态，怎么报都行；差别大，说明有偏或偏斜，应以 BCa 为准，并说明原因 |
| 比较自助标准误和公式标准误 | 公式所依赖的假设 | 两者接近，说明公式的假设问题不大；自助标准误大很多，原因往往是异方差、偏斜或被忽略的依赖 |
| 换重抽样单位 | 重抽的单位彼此独立 | 分别按观测、按国家、按地区重抽。换到更高一层后标准误明显变大，说明那一层的相关不能忽略，应当在更高层重抽 |
| 改变块的长度 | 块自助保留了时间相关 | 块自助的结果对块长不敏感才可信；块长一变结论就变，要报告不同块长下的结果 |
| 野聚类自助，换权重类型 | 样本足够大，这里指聚类足够多 | 聚类少时，把聚类稳健的 p 值和野聚类自助的 p 值并排。后者明显更大，说明原来的显著性来自聚类太少；聚类极少时，再比较 Rademacher 和 Webb 两种权重 |
| 两步整体重抽与只重抽第二步对比 | 重抽样复制了整个估计过程 | 整体重抽的标准误更大，差距就是第一步误差的贡献。差距大时，只报第二步的公式标准误会夸大显著性 |
| 逐个去掉聚类 | 结论不由少数聚类撑起 | 每次去掉一个国家重估。某个国家一去掉结论就变，自助区间再窄，也说明不了结论稳健 |

## 怎么读结果

- **论文里的说法**：「括号内为自助标准误，重复 1000 次」「按国家整体重抽」「野聚类自助 p 值」。要找三样东西：重复次数、重抽的单位、区间的类型。缺了任何一样，既无法判断结果可不可信，也无法准确复现。
- **Stata 的输出**：bootstrap 前缀命令的结果表里，标准误一栏标为 Bootstrap Std. Err.，表头的 Replications 是重复次数；有失败的重复时，输出会提示。`estat bootstrap` 列出正态、百分位、偏差校正、BCa 几种区间。
- **野聚类自助**：通常只报 p 值和由检验反推的置信区间，不报标准误。这个区间不一定关于点估计对称。
- **自助 p 值和区间的精度**：用上面的式子估一下蒙特卡洛误差。p = 0.048、B = 1000 时，能说的只是 p 在 0.05 附近，不能把「在 5% 水平上显著」当作确定的结论。
- **区间不对称**：百分位和 BCa 区间常常不关于点估计对称，这正是它们的意义所在，说明抽样分布是偏的。

读的时候可以这样说：按国家整体重抽 2000 次，估计值的 95% BCa 区间为 a 到 b，不含 0；换一个种子并重抽 10000 次，区间端点只在第三位小数上变化。

## 常见陷阱

- **按观测重抽聚类数据**：面板里抽国家—年份而不是国家，等于假定各年独立，标准误偏小。
- **聚类重抽后不改编号**：同一个国家被抽中两次，应当作为两个不同的聚类。仍用原来的国家编号，带国家固定效应的模型会把两份并成一个国家，组内变化被扭曲。Stata 的 bootstrap 用 `idcluster()` 生成新编号，自己写的代码要自己编。
- **只重抽第二步**：生成变量的不确定性被遗漏。
- **聚类很少还用成对聚类自助或聚类稳健标准误**：都偏乐观，应当用野聚类自助。
- **在循环里重复设置种子**：每次重复前都设同一个种子，每个自助样本完全一样，标准误为 0 或小得离谱。种子只在循环开始前设一次。
- **用默认的重复次数**：Stata 的 `bootstrap` 默认只重复 50 次，够估一个粗略的标准误，远不够算区间和 p 值。
- **把自助法当作纠偏工具**：它不能修复有偏的设计，也不能让小样本变大。
- **复杂抽样的调查数据**：直接对受访者重抽，忽略了分层和整群抽样的设计。应当用调查方提供的重复权重，或者按初级抽样单位重抽。

## 代码写法

R，常用 boot 包；聚类重抽可以自己写循环，野聚类自助用 fwildclusterboot：

```r
library(boot)
# 统计量函数：第一个参数是数据，第二个是本次抽到的行号
med_fun <- function(d, idx) median(d$y[idx])
set.seed(20240101)                 # 种子只设一次，放在 boot() 之前
b1 <- boot(df, statistic = med_fun, R = 2000)
boot.ci(b1, type = c("norm", "basic", "perc", "bca"))
# R 太小时 boot.ci 会警告 extreme order statistics used as endpoints，要加大 R；BCa 一般要 1000 次以上

# 自助 t 区间：统计量函数同时返回估计值和它的方差，boot.ci 默认把第二个元素当作方差
coef_fun <- function(d, idx) {
  m <- lm(y ~ x + w, data = d[idx, ])
  c(coef(m)["x"], vcov(m)["x", "x"])
}
b2 <- boot(df, statistic = coef_fun, R = 2000)
boot.ci(b2, type = "stud")

# 两步估计：每次重抽都把两步重做一遍
two_step <- function(d, idx) {
  d <- d[idx, ]
  s1 <- lm(x_raw ~ z1 + z2, data = d)         # 第一步：在本次自助样本上重新估计
  d$x_hat <- predict(s1, newdata = d)
  s2 <- lm(y ~ x_hat + w, data = d)           # 第二步
  coef(s2)["x_hat"]
}
b3 <- boot(df, statistic = two_step, R = 2000)

# 按国家整体重抽，带固定效应
library(fixest)
ids <- unique(df$country)
est <- replicate(999, {
  draw <- sample(ids, length(ids), replace = TRUE)
  # 重复抽中的国家给新编号 boot_id，否则国家固定效应会把两份并成一个国家
  d <- do.call(rbind, lapply(seq_along(draw), function(k)
    transform(df[df$country == draw[k], ], boot_id = k)))
  coef(feols(y ~ x | boot_id + year, data = d))["x"]
})
sd(est)
quantile(est, c(0.025, 0.975))

# 野聚类自助，原理与 Stata 的 boottest 相同；复现时按包的文档设定随机种子

summary(wb)
```

Python：

```python
import numpy as np
import pandas as pd
import pyfixest as pf

rng = np.random.default_rng(20240101)         # 种子只设一次
B = 2000

# 观测层面的自助：中位数
y = df["y"].to_numpy()
meds = np.empty(B)
for b in range(B):
    idx = rng.integers(0, len(y), size=len(y))  # 有放回地抽行号
    meds[b] = np.median(y[idx])
se = meds.std(ddof=1)
ci = np.percentile(meds, [2.5, 97.5])

# 按国家整体重抽，重复抽中的国家给新编号
ids = df["country"].unique()
groups = {c: g for c, g in df.groupby("country")}
est = np.empty(B)
for b in range(B):
    draw = rng.choice(ids, size=len(ids), replace=True)
    d = pd.concat([groups[c].assign(boot_id=k) for k, c in enumerate(draw)])
    est[b] = pf.feols("y ~ x | boot_id + year", data=d).coef()["x"]

# 野聚类自助；需先 pip install wildboottest，否则 pyfixest 报错
fit = pf.feols("y ~ x + w", data=df, vcov={"CRV1": "country"})
fit.wildboottest(param="x", reps=9999, seed=20240101)
```
